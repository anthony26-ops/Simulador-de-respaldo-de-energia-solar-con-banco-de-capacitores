# Simulador RC Solar

Simulador web de un sistema de respaldo de energía solar con banco de capacitores (circuito RC).
Proyecto final de Física II — Universidad Mariano Gálvez de Guatemala.

Es una página de un solo archivo (`index.html`): no requiere instalación ni servidor.
Todo el cálculo ocurre en el navegador.

## Cómo usarlo
- Abrir `index.html` con doble clic, o entrar al enlace de GitHub Pages del repositorio.
- Elegir un escenario de ejemplo o cambiar los valores del circuito.
- Opcional: escribir mediciones de laboratorio (tiempo en s, voltaje en V) para compararlas.
